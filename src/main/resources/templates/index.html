Gestion de Papelería CPCS

Aplicación web desarrollada con Spring Boot, Spring MVC, Hibernate, JPA, Thymeleaf y SQL Server para la gestión de productos de papelería.

Framework aplicado

El proyecto utiliza Spring para implementar una arquitectura por capas y Hibernate/JPA para gestionar la persistencia de datos.

Tecnologías

  • Java 21
  • Spring Boot
  • Spring MVC
  • Spring Data JPA
  • Hibernate
  • Thymeleaf
  • SQL Server
  • Maven

Funcionalidades

  • Registrar productos
  • Consultar inventario
  • Actualizar productos
  • Eliminar productos
  • Validar formularios
  • Persistir información
